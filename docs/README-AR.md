# دليل JOKSTREAM الفني والتشغيلي

> اللغة: العربية. هذا المجلد هو مرجع الصيانة والاستعادة. ابدأ من هنا قبل أي تعديل.

## الملفات

1. [نظرة عامة والمعمارية](ARCHITECTURE-AR.md) — الخدمات، تدفق البيانات، حدود كل مشروع.
2. [دليل الوظائف والتشغيل](FEATURES-AR.md) — البث المباشر، الأفلام، المسلسلات، المشغل، الترجمات، البحث والقائمة.
3. [الإعدادات والنشر والصيانة](OPERATIONS-AR.md) — المتغيرات والأسرار، النشر، الفحص، سجل الإصدارات.
4. [النسخ الاحتياطي والاستعادة](RESTORE-AR.md) — طريقة الرجوع إلى النسخة السليمة خطوة بخطوة.
5. [خط الأساس المعروف أنه يعمل](KNOWN-GOOD-BASELINE.md) — commit وملفات النسخة المرجعية التي أنشأنا منها نقطة استعادة.

## قاعدة ذهبية

- لا تعدّل `jokstream-api` مطلقاً أثناء العمل على واجهة JOKSTREAM إلا بطلب مستقل وصريح.
- لا تغيّر عدة أنظمة في عملية واحدة. عدّل مكوّناً واحداً، اختبره، ثم انتقل للذي بعده.
- قبل التعديل: سجّل commit الحالي وأنشئ نسخة احتياطية/فرعاً.
- بعد التعديل: افحص التغييرات، انشر، ثم اختبر السيناريوهات الموجودة في قائمة الاختبار.
- لا تضع مفاتيح TMDB أو OpenSubtitles أو أي سر في ملفات الموقع أو التوثيق أو GitHub.
- لا تعتبر وجود commit على GitHub دليلاً على نجاح التشغيل. يجب إجراء اختبار فعلي على الموقع.

## النطاق

هذا التوثيق مبني على ملفات المستودع الحالي وعلى سجل النشر المعروف بتاريخ 2026-11-21. بعض التفاصيل الداخلية لـ `jokstream-api` و`jokflix` موثقة من واجهات الربط المعروفة فقط؛ لا يفترض هذا الدليل مخطط قواعد البيانات أو أسماء bindings غير مؤكدة.

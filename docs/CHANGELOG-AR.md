## إصدارات وظيفية كبرى

### مرحلة معرّف التشغيل
استخدم الكود IMDb ID من كتالوج VidSrc عندما يتوفر، لتقليل احتمال تمرير TMDB ID غير مناسب إلى مشغل embed.

### مرحلة حماية المشغل والتحكم الخارجي
أضيفت حماية النقر التلقائية، وتحقق أصل الرسائل، ثم مواءمة التحكم مع بروتوكول VidSrc. بحسب اختبار المستخدم في المحادثة، أصبحت أزرار التحكم الخارجية تعمل، وسلوك النوافذ المنبثقة مقبولاً.

### مرحلة vidsrc.sh
أصبح مشغل VOD يستخدم `vidsrc.sh` ومسارات:
- Movie: `/embed/movie/{id}`
- TV: `/embed/tv/{id}/{season}/{episode}`

لا تخلط هذا مع commits الأقدم الخاصة بـ vidsrc.su؛ تلك مراحل تاريخية سابقة.

### مرحلة لغات الترجمة
القيمة الافتراضية في النسخة المرجعية: `ar,es,fr`. يتم تمريرها كأولوية إلى `ds_lang` بعد تنظيفها وقصرها على ثلاثة رموز. هذه أولوية لمسارات موجودة عند المزود وليست توليداً للترجمات.

## سياسة الترقيم مستقبلاً

استخدم إصدارات داخلية بسيطة مثل:
- `JOKSTREAM-2026.11.21` — النسخة المرجعية.
- `JOKSTREAM-2026.11.22` — أول دفعة تغييرات جديدة بعد اختبارها.
- `JOKSTREAM-2026.11.23` — الدفعة التالية.

لكل إصدار جديد سجّل:
1. رقم الإصدار وتاريخ UTC.
2. commit SHA قبل التعديل وبعده.
3. الملفات التي تغيرت.
4. سبب التعديل.
5. ما الذي تغير للمستخدم.
6. الاختبارات التي نجحت والتي لم تُجرَ.
7. هل تم نشر Worker؟ وما اسم Worker؟
8. رابط backup branch جديد بعد نجاح الاختبار.

لا تكتب "تم الاختبار" إلا بعد اختبار فعلي. لا تعتبر تحديث cache أو إنشاء commit إصداراً وظيفياً مستقلاً ما لم يكن كذلك.
